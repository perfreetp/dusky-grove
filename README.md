# 冰川雪桥日照通行模拟

使用 **PixiJS 8** 与 **pixi-viewport 7** 绘制的俯视冰川地形交互。场景中有多道冰裂缝、露出的梯形深槽、被雪桥覆盖的桥段，以及一条包含三座雪桥的结组路线。

## 运行

```bash
npm install
npm run dev
```

浏览器打开 Vite 输出的本地地址（默认 `http://127.0.0.1:5173`；若端口被占用，以终端实际输出为准）。

生产构建：

```bash
npm run build
npm run preview
```

模型窗口检查：

```bash
npm run check
```

## 交互

- 滚轮缩放，拖拽空白处或地形平移。
- 点击白色雪桥或地图上的编号点，侧栏显示厚度、桥下阴影浓度、太阳入射角、阴影覆盖率和通行判定。
- 拖动时刻滑块或点击“从清晨演示”，太阳方位角/高度角会沿预置清晨至正午路径变化。
- 也可以直接拖动太阳方位角、高度角和坡度，观察阴影方向与覆盖率变化。
- 侧栏“三桥窗口次序”和时间条显示各雪桥大约何时失去通行窗口。

## 判定模型

地图坐标采用 x 向东、y 向南；方位角从北顺时针计量。太阳向量为：

```text
S = (cos h sin A, -cos h cos A, sin h)
```

冰川坡度为 β、坡向为 D，坡度梯度：

```text
g = tan β
grad z = -g · azimuthVector(D)
```

高度 H 的遮挡物在坡面上的阴影位移为：

```text
q = -H · S_h / (S_z - grad z · S_h)
```

因此阴影方向同时取决于太阳方位/高度、坡度和坡向。裂缝横截面简化为梯形，`q` 投影到裂缝法向得到横向阴影覆盖，投影到裂缝走向得到沿缝漂移。

通行判定严格使用：

```text
可通行 = 桥面被直射阳光照亮 且 阴影覆盖率 < 98.5%
```

雪桥厚度只控制桥端/桥下阴影浓度与侧栏数据，不直接替代上述两个通行条件。

## 主要文件

- `src/model.js`：地形、裂缝/雪桥数据、太阳向量、坡度阴影、通行窗口计算。
- `src/scene.js`：PixiJS/pixi-viewport 渲染、梯形裂缝、雪桥、路线和点击拾取。
- `src/main.js`：控制台、侧栏、时间轴和状态同步。
- `src/style.css`：响应式侧栏与仪表盘样式。
