# 料仓与输送辊道三维布置工具

面向分选线设备工程师的三维布置工具：录入设备厂商目录与现场测绘约束，按处理量/果径档定节拍，
在 PlayCanvas 三维场景中拖入料仓与辊道、调整辊距与落料口（带吸附提示），一键投放仿真果实做
通过性检查，卡果定位到具体辊间，支持撤销/重做与前后卡果对比，最终出料仓布置方案与辊道装配
尺寸表交付车间。

技术栈：**SolidJS 1.9（响应式 UI/状态）+ PlayCanvas 2.24（WebGL 三维引擎）+ Vite 8**。

## 启动

```bash
npm install
npm run dev      # http://127.0.0.1:5180
npm run build    # 生产构建到 dist/
```

## 操作指引（对应工程师工作流）

1. **新建方案向导**：录入方案名/设计人、每小时处理量、果径档位区间；维护厂商辊道/料仓目录
   （辊径、带宽系列、节距范围、最大倾角、料仓尺寸与出料口范围）；录入现场测绘的车间长宽与
   可布置 X 区间。
2. **节拍推算**：左侧按处理量与当量果径估算单果质量、果量（果/小时、果/分钟）与建议带速。
3. **场景布置**
   - 从左侧设备库**拖**辊道/料仓卡片到三维视口，落点即世界坐标。
   - 左键**拖辊子**改辊距（自动吸附各果径档安全辊距边界、厂商上下限，实时显示辊子数）。
   - 左键**拖段框架**移动整段（吸附相邻段端点、车间边界、输送中心线）。
   - 左键**拖蓝色落料口**横向对位分拣机构（吸附段中心线），按住 **Shift 拖**改口宽。
   - 左键**拖料仓**移动位置。拖动时底部显示吸附提示，松手后间距/位置回写右侧数值栏。
   - 视角：空白处左键拖动旋转、右键平移、滚轮缩放。
4. **属性编辑**：选中段可改皮带宽度（厂商系列下拉）、倾角（滑块，超厂商限/低于 3° 有提示）、
   辊距、落料口档位与对接机构；选中料仓可改出料口高度/口宽（滑块，受厂商范围约束）。
5. **通过性检查**：点击「投放果实并检查卡果」，按档位从料仓侧沿辊道投放，果实滚动到落料口；
   卡住的果实停在原地、染红，红色定位柱 + 文字标注**第 N 与第 N+1 辊之间**及卡果原因。
6. **改后重跑对比**：调整任意参数后再次检查，右侧给出各档/合计卡果数的前后差值。
7. **撤销/重做**：`Ctrl+Z` / `Ctrl+Y`（或顶栏按钮），拖拽整体合并为一条历史；`Delete` 删除选中。
8. **交付**：右侧导出「料仓布置方案.txt」（定位/尺寸/安装注意事项）与「辊道装配尺寸表.csv」
   （段级参数 + 逐辊放线坐标，UTF-8 BOM，Excel 直接打开）。

顶栏「重载 8t/h 教学示例」内置完整故事场景：李工 8 t/h 线，75mm 档在第三段落料口前卡 3 颗，
点「一键修复：60→72 重跑」后卡果清零，再撤销可回到原布局。

## 架构与关键设计

```
src/
├── model.js          领域模型、厂商目录/实例工厂、节拍推算（mm 数据域）
├── check.js          通过性检查引擎（确定性种子随机 + 卡果规则 + 前后对比）
├── store.js          Solid store + 快照式撤销/重做（拖拽合并为单条命令）
├── scene-geo.js      渲染/拾取数学（mm↔m、辊子位姿、解析射线求交、吸附）
├── exporter.js       料仓方案 TXT + 辊道装配 CSV 导出
├── example.js        8t/h 教学示例
├── engine/
│   └── scene-engine.js  PlayCanvas 引擎封装（实例化/拾取/拖拽吸附/果实动画）
└── components/       Wizard / LeftPanel / Viewport / RightPanel
```

- **数千对象流畅**：辊子与果实各自只用一个共享网格 + GPU 实例化（`MeshInstance.setInstancing`），
  辊子按「普通/选中」两个材质批次，全场景辊子 draw call 为个位数；静态框架/料仓才建实体，
  实体数量与辊子总数无关。共享网格用 `incRefCount()` 保护，避免实体重建时缓冲被引用计数释放。
- **拾取不依赖实体**：屏幕射线走解析求交（圆柱/ AABB），先做段级 AABB 粗筛再逐辊精算，
  悬停拾取 80ms 节流，几千辊子不卡。
- **检查可复现**：随机数种子由「检查轮次 + 段 + 档位 + 果实序号」哈希派生，同布局同轮次结果稳定。
- **卡果规则**（阈值集中在 `check.js` 的 `RULES`，可调）：辊距过紧挤压、辊隙过大楔入、
  落料口过小卡料/过大漏果、低倾角滞留。
