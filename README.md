# 高空舞台 · 钢梁剖面（交互页）

单文件网页，无构建依赖：打开 `index.html` 即可（Konva 从 cdnjs 加载，需联网）。

## 力学模型

- **梁**：Euler–Bernoulli，2 节点/单元、Hermite 三次形函数、位移法；带状 LU（带宽 3）求解，末端用 40 单元/米。
- **吊点**：竖向弹簧，`R_i = k_i·v_i`。四个吊点刚度刻意不等（150 / 30 / 70 / 800 kN/m），
  因此反力按刚度分配、**不是平均分**。页面上给出平均分配值作对照与偏差百分比。
- **只受拉**：反力出现负值时该吊点脱开（k→0）后重解，迭代到全部非负或只剩一个吊点。
  这是连续梁在外伸段承受荷载时的真实行为（与独立 FE 参考值一致）。
- **自重**取 0.50 kN/m，按单元一致荷载向量加载。

## 交互

| 操作 | 效果 |
| --- | --- |
| 拖动演员 | 演员位置改变 → 重算四个吊点反力与整条挠度曲线 |
| 「载入偏载布局」 | 两人回到 0.98 / 1.84 m，吊点 2 受力最大、最远端吊点 4 最小 |
| 「中跨重载」 | 两人站 3.30 / 4.50 m，峰值 128 mm 超限，窗口净空降到 293 cm |
| 「抛起一次」 | 乙被抛向抛接窗口，窗口跟着飞行的演员移动，绳张力受防坠器限力（1.8 kN）|
| 剖切滑块 | 沿梁长切一刀，读该处梁底到垫面/台面的净空，并与需求净空比对 |
| 挠度限值滑块 | 改限值，梁体超限区段变红、曲线红段同步 |
| 吊点刚度滑块 | 四个吊点同比缩放，观察挠度与反力重分配 |
